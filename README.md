# 42 Common Core Portfolio

Welcome to the centralized repository documenting my journey through the 42 Common Core curriculum. This space serves as a comprehensive archive of my progress, housing all the projects, algorithms, and systems I build as a cadet.

## 🎯 Purpose
The goal of this repository is to keep all my 42 projects organized in a single location, tracking my evolution from fundamental C programming in `libft` to advanced system architecture, networking, and object-oriented programming. It serves as both a personal tracker and a professional portfolio.

## 🚀 The Journey
As I progress through the curriculum, this repository will grow to include projects across several core domains:

* **Algorithms & Data Structures:** Sorting algorithms, tree traversal, and complex data management.
* **System Programming:** Memory management, process creation, file descriptors, and IPC.
* **System Administration:** Virtualization, bash scripting, and strict server configuration.
* **Graphics & Mathematics:** Raycasting, fractals, and 3D rendering.
* **Object-Oriented Programming:** Transitioning to C++ and building robust, scalable applications.
